# NOKAY

**Ideas into digital experiences.**

NOKAY is a creative and technology-focused digital agency building showcase websites, web applications and SaaS products, complemented by graphic design and digital communication services.

## Product scope

- Showcase websites
- Custom web applications
- SaaS products
- Brand identity, graphic design, UI/UX and motion design

> Hosting and cloud infrastructure are outside NOKAY's initial commercial service scope and are handled by a separate provider.

## Languages

French and English.

Foundation phase — architecture and application bootstrap.
